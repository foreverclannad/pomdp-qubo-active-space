Data and Software Availability

The PAS source code, computational inputs, archived calculation results, and scripts used to reproduce the active-space selections and analyses are available at https://github.com/foreverclannad/pomdp-qubo-active-space. Release 1.0.0 (https://github.com/foreverclannad/pomdp-qubo-active-space/releases/tag/v1.0.0) includes the dioxetanone, TiF3, and small-molecule data, installation instructions, runnable examples, reference results, and file checksums.
