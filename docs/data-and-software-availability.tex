\section*{Data and Software Availability}
The PAS source code, computational inputs, archived calculation results, and scripts used to reproduce the active-space selections and analyses are available at \url{https://github.com/foreverclannad/pas-active-space}. Release 1.0.0 (\url{https://github.com/foreverclannad/pas-active-space/releases/tag/v1.0.0}) includes the dioxetanone, TiF$_3$, and small-molecule data, installation instructions, runnable examples, reference results, and file checksums.
