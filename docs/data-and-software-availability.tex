\section*{Data and Software Availability}
The PAS source code, computational inputs, archived calculation results, and scripts used to reproduce the active-space selections and analyses are provided in the Supporting Information ZIP archives. The data cover the dioxetanone, TiF$_3$, and small-molecule examples reported in this work. Installation instructions, software requirements, example commands, and file checksums are included.
